---

A solo instance moves to enterprise mode with everything in it: connections, storage, SSH hosts and keys, dashboards, workflows, the
workspace and its settings. You keep your id, so you keep owning all of it.

<Steps>
  <Step title="Deploy Hayat">
    Use [the bundled setup](/docs/enterprise#bundled), [Hayat's compose file](/docs/enterprise#deploy-hayat), or a Hayat you already run.
  </Step>
  <Step title="Write the import bundle">
    ```bash
    docker compose exec tabletsgo npm run hayat:bundle -- --out /app/data/hayat-import.json
    docker compose cp tabletsgo:/app/data/hayat-import.json .
    ```

    It holds you, your workspace (as a Hayat tenant with the same id) and every connection and storage destination you own.
  </Step>
  <Step title="Load it into Hayat">
    ```bash
    hayat import --file hayat-import.json --out hayat-result.json
    ```

    With the bundled Hayat, pipe it straight from one container to the other:

    ```bash
    dc exec -T tabletsgo cat /app/data/hayat-import.json | dc exec -T hayat hayat import --file /dev/stdin --app-url http://localhost:3000
    ```
  </Step>
  <Step title="Restart in enterprise mode">
    Add `TABLETSGO_MODE=enterprise`, `HAYAT_ISSUER`, `HAYAT_API_URL` and `ENCRYPTION_KEY` to your settings. If solo generated the key,
    copy it so saved credentials stay readable:

    ```bash
    docker compose exec tabletsgo cat /app/data/encryption.key
    ```

    Then start again. With the repo's files:
    `docker compose -f docker-compose.yml -f docker-compose.enterprise.yml up -d` (or `docker-compose.hayat.yml` for the bundled Hayat,
    which sets the mode and Hayat's addresses itself). The log shows `🔁 Mode: solo → enterprise`.
  </Step>
  <Step title="Enroll and sign in">
    Open Tabletsgo and paste an enrollment code, as in [Enterprise mode](/docs/enterprise#set-up). Then sign up at Hayat with the
    owner's email: that account takes your id, and with it everything you owned.
  </Step>
</Steps>

<Callout kind="note" title="Hayat already knew your email?">
  If `hayat import` said `1 people matched existing accounts under other ids`, point your data at that account:

  ```bash
  docker compose cp hayat-result.json tabletsgo:/app/data/hayat-result.json
  docker compose exec tabletsgo node scripts/hayat-remap.js /app/data/hayat-result.json
  ```

  Then sign in with the account you have.
</Callout>

Your password doesn't move: you choose one when you sign up at Hayat.

<H2 id="no-workspace">Connections from before workspaces</H2>

A connection created before workspaces existed belongs to none, and nobody may open it. The move files each one under its owner's
oldest workspace. If the log still says `⚠️ N connection(s) belong to no workspace`, file them under one yourself:

```bash
docker compose exec tabletsgo npm run connections:assign -- --workspace <workspace id>
```

Then grant access to them in Hayat's console as usual.

## Going back

An instance that has run in enterprise mode won't start in solo mode. To work alone again, export the connections you want and import
them into a new solo instance.
